# 公共数值输入与未定义结果

数值接口在计算前拒绝非有限输入及无效范围，抛出带参数含义的 `ValueError`；GUI 捕获为失败状态，CLI 保留明确错误。已有 DOS、带隙和导数契约分别说明其具体单位与容差。

- DOS：σ 必须有限且正，能量窗口有限递增，至少两个能量点，网格尺寸为正整数，权重有限非负且总和非零。
- 带边和导数：填充/带索引合法；差分步长有限且正，方向有限非零，Cartesian 方向位于所分析平面。路径至少两个已定义端点，每段至少两个点；完整三维倒格度量保留倾斜 slab 的距离。
- TB：位点数量/索引为整数，元素列表与在位能长度匹配，在位能/位移/跃迁有限。k 坐标严格为 2 或 3 分量；同位点跨胞跃迁需要共轭配对，非厄米矩阵明确拒绝。
- 单带 Berry/轨道磁矩：有限坐标、正步长和合法带索引；选定带的简并间隔 ≤10⁻¹⁰ eV 时，单带量未定义，明确拒绝。谷热图使用奇数网格以包含实际中心，积分网格及半径合法。
- 激子：质量/介电常数/屏蔽长度/径向盒尺寸有限正值；基组和返回态数为正整数，返回态数不超过基组维度，求积点数至少为基组数加一（且至少 3）。势函数不在 r=0 的奇点直接求值。

激子结果的 `status` 为 `bound-states-found`、`partial-bound-spectrum` 或 `no-bound-state`。`requested_levels` 记录请求数，`bound_states_in_basis` 记录有限基组得到的负能量数；实际返回可少于请求。无负能量时 `binding_1s=None`、`energies` 为空，不发生索引错误。这是有限径向盒/基组的数值结果，不证明无限域不存在束缚态；物理结论需要尺寸、求积与基组收敛。

回归包括真实小盒无束缚态、部分束缚谱、倾斜路径旋转、合法配对的解析余弦色散、非厄米/简并拒绝，并将无效输入的 RuntimeWarning 当作错误检查。
