# 取消与关闭契约

两个窗口提供取消按钮。后台用协作检查抛出 InterruptedError，作为取消状态处理；常规异常作为失败，完整诊断写日志。仿真采样、带边局部优化、DOS 分块、谷图逐行计算及 VASP 解析块均设置检查点。原生对角化、系统读取等单次调用不能被安全抢占，取消在调用返回到下一个检查点时生效。

运行中关闭请求取消并暂不接受 closeEvent，保持 worker 引用和 Qt 事件循环；检测线程自然退出后再次关闭。程序不调用 terminate，也不在主线程同步等长任务。关闭阶段忽略结果与失败弹窗；后台计算从不直接操作 QWidget。

BandViz 保存所有运行/退休 worker，线程停止后给已排队的 Qt 通知处理机会，再 deleteLater；加载任务编号与 DOS 请求版本防止旧结果覆盖新输入。成功、失败、取消均恢复 UI；失败加载保留前一个文件及其数据身份。

谱刷新捕获数据引用、文件和完整显示参数，180 ms 单次定时器合并短时间改动；工作在独立 QThread 中进行，旧请求取消/丢弃。导入期间锁定相关参数；后台谱刷新期间允许继续调参。DOSCAR 只平移显示零点，不重新展宽。图上注明实际 σ 与当前窗口积分，取消刷新时原图仍对应其标注参数。

vdW Studio 用同一轮询定时器处理进度/完成。取消后不发布部分结果；线程停止后恢复按钮与控件，关闭中继续轮询到安全退出。材料/参数快照契约见 TASK_SNAPSHOTS.md。

回归通过真实事件循环和受控后台阶段验证持续 GUI 响应、两个窗口关闭延迟、取消、连续加载、错误恢复、防抖、线程身份、过期结果及全部检查点中断。平台专属驱动/原生库行为仍以实际环境为准，测试不依赖强制终止。
