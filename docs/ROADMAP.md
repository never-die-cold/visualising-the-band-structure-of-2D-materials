# vdW Studio 路线图（科研前沿功能规划）

近期工程待办、已复现缺陷与验收标准见 [项目检查与改进计划（2026-10-09）](PROJECT_REVIEW_PLAN.md)。先完成核心流程与数值可靠性修复，再推进下列研究扩展。

本文档规划 vdW Studio 的中长期发展方向。原则：**每项功能对应一个明确的
物理模型 + 可验证的文献基准**，先框架后参数，与"防幻觉"自检机制配套。

## Phase 1 — 基础平台（常规入口已实现，SK 待验证）

- ✅ 材料结构库（11 种二维材料，文献结构参数）
- ✅ 位点紧束缚引擎（石墨烯/hBN/硅烯/黑磷烯，物理验证对账）
- ✅ TMD k·p 引擎（6 种材料，谷-自旋物理，与 Kormányos 2015 对账）
- ✅ sp³d⁵ Slater-Koster 框架（MoS₂ 96 参数，H/S 厄米 + S(k) 正定）
- ✅ 性质分析（带隙/有效质量/主质量/费米速度）
- ✅ 可视化 + PyQt5 图形界面 + CLI
- ⬜ **sp³d⁵ 引擎带隙验证**（科研验证待办）：需确认 Nanoskif SK 相位约定
  （候选：Zahid 博士论文 / Klimeck NEMO-3D 文档 / Papaconstantopoulos 手册），
  目标：单层 K_v1→K_c = 1.805 eV

## Phase 2 — 应变与外场工程（近期）

二维材料的"杀手锏"调控手段，全部可在现有引擎上以低垂果实实现：

1. **双轴/单轴应变**（`Lattice.scaled_xy` 已就绪）
   - 结构：晶格缩放；引擎：hopping 随键长缩放（Harrison 定则 t ∝ d^−n
     或指数标度），重算能带
   - 验证锚点：石墨烯费米速度随应变的变化（文献有 DFT 标准曲线）；
     MoS₂ 带隙随双轴应变的线性斜率 (~−45 至 −100 meV/%，文献区间)
2. **垂直电场**（硅烯已实现 ✅）
   - 扩展到双层体系：双层石墨烯栅极调隙 (McCann 2006 模型)
3. **层间滑移/堆叠**：2H/3R TMD 双层堆叠，层间 hopping 切换

## Phase 3 — 介电环境与激子物理（已完成 ✅）

二维材料激子束缚能高达数百 meV，是区别于体材料的核心物理：

1. ✅ **Rytova–Keldysh 屏蔽势** V(r)
   V(q) = e²/[2ε₀q(1 + r₀q)]，r₀ = 2πχ₂D（二维极化率）
   - 文献锚点：Cudazzo, Tokatly & Rubio, PRB 84, 085406 (2011)；
     Berkelbach, Hybertsen & Reichman, PRB 88, 045318 (2013)
2. ✅ **2D 激子束缚能求解器**：Fourier–Bessel DVR + 广义本征值
   （库仑极限 2D 氢谱 <2% 对账）
3. ✅ **材料默认值文献标定**（2026-10-07）：MoS₂/MoSe₂/WS₂/WSe₂ 的
   μ、χ₂D 取 Berkelbach 2013 Table，r₀ = 2πχ₂D；精确 DVR 解与
   文献变分束缚能对账（≥ 变分下界，偏差 2–5%），材料排序复现；
   `presets.solve_preset_exciton()` 一键使用
4. ✅ **衬底/介电环境扫描**：API 与高通量示例；GUI/CLI 的 ε_env 控件尚未接入

## Phase 4 — 谷-自旋物理深化（基本完成）

现有 k·p 引擎已包含完整谷-自旋结构，向前推：

1. ✅ **Berry 曲率与 valley Hall**（Xiao et al. PRL 108, 196802 (2012) 公式，
   k·p 模型解析式 + 数值验证）
2. ✅ **谷磁矩/谷 Zeeman 效应**（2026-10-07）：轨道磁矩通式
   （Xiao–Chang–Niu RMP 2010 波包表述）+ 带边 μ*_B = (m₀/m*)μ_B +
   谷劈裂 ΔE = −2m·μ_B·B；三路独立实现对账（FD 原式 / 速度矩阵元 /
   两带解析）
3. ✅ **谷选择光学定则**：σ+/σ− 跃迁强度表（GUI 可视化）
4. ⬜ **(模拟) 输运性质**：玻尔兹曼输运 → 迁移率（配合磷烯各向异性质量）

## Phase 5 — 莫尔超晶格与转角体系（实验性，T16 验证中）

1. ✅ **转角双层石墨烯 BM 连续模型**（2026-10-07）：
   `engine/moire.py` 平面波展开（任意转角，无需公度）；
   验证锚点：第一壳层 v*/v = (1−3α²)/(1+6α²) 精确复现、
   **魔角 θ = 1.05° 数值复现**（BM Fig. 3）、k=0 双零模、
   魔角平带 ~8 meV（2° 时 ~110 meV）
2. ⬜ **全域平带验证**：已有示例出图与局部锚点；先通过有限 k 的 C₃、周期性与截断收敛门槛，再报告可靠平带域
3. ⬜ **转角 TMD**：moiré 激子（层间激子随转角的振荡）
   ——可在现有 BM 框架上换 TMD k·p 层哈密顿量
4. ⬜ 大超胞求解器优化（连续模型已规避大超胞；稀疏化按需）

## Phase 6 — 平台化（远期）

1. **高通量批量筛选**：材料 × 应变 × 介电环境的参数扫描 + 数据表导出
2. **机器学习代理模型**：对批量 TB/DFT 数据训练带隙预测器（scikit-learn）
3. **DFT 接口深化**：读取 VASP PROCAR（投影能带/轨道分辨 DOS）、
   bandstructure 输入直接对接 BandViz
4. **结果数据库**：SQLite 记录每次仿真（沿用 Pi 版的 storage 模块设计）
