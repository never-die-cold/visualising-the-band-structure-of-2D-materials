# 任务快照与结构一致性

`SimulationSnapshot` 用 frozen dataclass、嵌套 tuple 和不可变 JSON 字符串记录任务编号、材料/来源、引擎、模型运行参数、晶格和原子分数坐标、Cartesian 应变、电场、填充、路径顶点、DOS/带边网格、σ、路径采样数及谷分析开关。模型状态包含类名、运行参数、位点在位能和 hopping 表等；运行时代码版本与外部参数表的完整复现仍由 T13 完善。

后台线程拥有独立深拷贝的模型和材料晶格；初始化时核对模型状态与快照一致。即使外部改变原模型数组、结构或参数，也不改变已提交计算。快照提供独立结构恢复与可 JSON 导出的元数据，GUI 结果和 CLI summary 保存任务身份。局部 k·p 路径记录实际局部端点，而非把 Γ/M 原点伪装成局部端点。

GUI 运行时锁定材料及相关参数。程序化切换 combo 也会被运行守卫还原；过期任务编号不得覆盖当前结果。材料或参数改变后清除旧计算结果与图表，要求重新运行，避免把旧分析混到新结构上。完成状态、文献参考与模型质量使用提交任务的上下文。

结构始终从原始材料几何重新构建，按实际模型晶格显示和导出。TB 的分数原子位置保持固定，Cartesian 位置跟随晶格；SK 使用模型自身的原子位置。重复重建不累积应变。结构图、工程树和 POSCAR/XYZ 均使用该结构。

工程应变 ex/ey 表示 Cartesian x/y：行晶格 `A' = A @ diag(1+ex, 1+ey, 1)`。此前代码按两支基矢分别缩放，在非正交格子中不是 Cartesian 应变；已通过独立原子位移和晶格张量断言修正。普通 xy slab 的 z 真空与层间高度不变。应变必须有限且大于 −1；Harrison 标度指数有限且为正。

回归覆盖 immutable 元数据、模型/结构修改隔离、错误模型与快照拒绝、局部路径坐标、双层几何与 slab 高度、+2% 石墨烯 POSCAR 与工程树 a=2.5092 Å、零应变还原，以及真实线程/事件循环的运行中切换和过期结果拒绝。取消、关闭与后台重计算生命周期由 T09 继续处理。
